# Contributing

Thanks for helping keep Cantonese AI output authentic! 多謝幫手！

## What we need most

1. **Lexicon entries** — new written-Chinese → colloquial mappings, or Mandarin-isms for the banned list. Include an example sentence.
2. **Slang freshness reviews** — flag entries in section C of `lexicon.md` that feel dated. Slang expires; native judgement rules.
3. **Few-shot pairs** — bad (written) vs good (colloquial) examples for new formats (email, forum reply, video captions…).
4. **TTS engine notes** — pronunciation quirks of specific Cantonese TTS voices/engines.

## Ground rules

- Hong Kong Cantonese is the reference variety (香港粵語為準).
- Keep entries colloquial-register — this skill is for 口語, not formal 書面粵文.
- One PR per logical change; include before/after examples.
- Native speaker review required before merge for lexicon changes.

## How

Fork → branch → PR with a short description (EN or 廣東話 both fine).
