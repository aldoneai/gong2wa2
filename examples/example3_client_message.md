# Example 3 — Client Message（期望管理）

## Prompt
> 用廣東話寫一個 WhatsApp message 俾客：個 project 要延遲一星期交，語氣專業但唔好官腔。

## Without skill
> 您好，關於項目進度，由於部分工作比預期複雜，我們需要延遲一星期交付，不便之處敬請原諒。

問題：「您好/由於/交付/不便之處敬請原諒」= 官腔書面，香港客一睇就覺得係罐頭 message。

## With skill
> Hi 你好！同你 update 下個 project 進度 🙏
> 有部分嘢做落發現複雜過預期，想做好啲，所以交貨期需要推遲一個星期。
> 唔好意思要你等多陣！有咩想傾隨時搵我。

要點：口語底 + professional tone 並存；英文淨係夾名詞（update/project）；語氣真誠唔官腔。
QC score: 5/5。
