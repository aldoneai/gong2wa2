# Example 2 — TTS Voice Script（客服語音回覆）

## Prompt
> 寫一段廣東話客服語音稿：客人問幾時發貨，訂單已寄出，運費 $30，兩三日到。準備俾粵語 TTS 讀。

## Without skill
> 您好，您的訂單已經發出，運費為30元，預計兩至三天內送達，謝謝您的耐心等待。

問題：「您/已經發出/預計/送達」全書面；「30元」TTS 會讀成普通話式數字；成句似錄音系統。

## With skill（已跑 TTS pre-processing）
> 你好呀！你張單已經寄咗出去喇。
> 運費係三十蚊，大約兩三日就到㗎喇。
> 有咩問題隨時搵我哋啊，唔使客氣！

TTS 處理位：金額轉中文數字（三十蚊）、句子 15-20 字內用標點斷句、無 emoji 無符號。
QC score: 5/5。
