## B. Banned Phrases（Mandarin-isms — 見到即改）

| ❌ Banned | 點解 | ✅ 替代 |
|---|---|---|
| 首先…其次…最後 | 書面框架 tell | 第一…跟住…最尾 |
| 其實這樣 | 書面 | 其實咁樣 |
| 然而/因此/故此 | 書面連接詞 | 但係/所以 |
| 非常 | 書面程度詞 | 好/勁/超 |
| 進行（進行討論） | 官腔 | 直接用動詞：傾 |
| 透過/通過 | 書面 | 靠/用 |
| 以及 | 書面 | 同埋 |
| 甚麼 | 書面拼法 | 乜嘢/咩 |
| 大家好，今天… | 普通話 opener | 哈囉大家／今日想講… |
| 讓我們 | 普通話 | 不如我哋 |
| 是不是 | 普通話 | 係咪 |
| 有沒有 | 普通話 | 有冇 |
| 看看/試試 | 普通話疊字 | 睇下/試下 |
| 挺好的 | 純普通話 | 幾好喎 |
| 靠譜/給力/牛逼 | 大陸 slang | 穩陣/勁/犀利 |
